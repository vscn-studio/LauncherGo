# 地图瞬间、管理配置与玩家跟踪

2.7.1 最终网页已撤下“瞬间”和玩家跟踪入口；下述相应章节仅记录保留的实现，不代表当前可访问的网页功能。图片上传、图片管理、图层策略和玩家额度配置仍可使用。

需要同时更新 ServerMap 模组和地图 WebRoot；只更新网页不能启用新 API。

桌面顶部操作栏与坐标、搜索框同高，右侧栏恢复满高；窄窗口顶部控件自动换行避让侧栏。语言入口为 Tabler `language` 图标，点击打开设置弹窗，保留全部八种语言与本地记忆，选择后立即生效。

## 图片

- 新上传默认 10 MB，可在管理窗口设置 1–50 MB，默认类型为 JPEG、PNG、WebP、BMP。允许列表可通过输入框扩展，例如添加 `gif`；类型名不再限制为固定四种，但实际文件仍须被服务器解码器支持。服务端按实际解码格式校验，不相信扩展名。
- 最大边长 8192 像素，总计最多 3200 万像素；没有单独的动图禁令。静态图按 EXIF 方向还原后重编码为全分辨率 PNG；GIF、APNG、动画 WebP 的展示图保留帧与播放控制，只保留图像所需块，去除 GPS、EXIF、XMP、文本注释等隐私元数据。所有图片另生成最长边 480 的静态 WebP 缩略图。APNG 归入 PNG 类型，动画 WebP 归入 WebP 类型；GIF 默认未允许，添加到类型列表后启用。
- 新展示图使用 `poi-image?size=0`；旧图片缺少原图时回退已有的 1280 WebP，不迁移或删除旧数据。旧的 `size=1280` 请求也兼容新展示图。
- “瞬间”使用展示图，桌面三列瀑布流（保持原窗口宽度）、手机两列；标题右侧有搜索框和搜索按钮。悬浮、键盘聚焦或触屏展示名称、描述和图片添加者。旧记录没有添加者时显示标记所有者。
- 管理员删除图片只清除标记的图片关联，标记本身保留。已解除关联的图片文件留在世界地图目录的 `poi-images` 下以便备份恢复，旧 URL 不再可访问。恢复需从备份恢复标记记录与相应文件；文件不会自动清理。

## 管理配置

配置保存在现有 `announcement.json` 的 `Management` 中。旧设置保存请求不会重置新增配置。首次读取沿用原有 `MaxPoisPerPlayer`（默认 10）。

- 默认图层勾选只用于没有个人偏好的图层；禁止和强制开启会覆盖个人偏好，并锁定复选框。禁止图层的要素接口返回空集合。
- 只有玩家、坐骑、传送器支持样式倍率 0.1–10，默认 1；其他图层固定为 1，包括兼容已有设置。
- 图片上传类型使用文本框，逗号或空格分隔；提交时规范化大小写、JPG/JPEG、APNG/PNG 别名。不因图片含动画额外拒绝上传。
- 地点额度降低不会删除已有标记，仍可编辑旧标记。地点额度 0 表示不能创建新标记。
- 每日传送次数 0 表示无限，按服务器本地日期换日，存储在 `teleport-quota.json`。成功的普通玩家传送计一次；同乘者每人各计一次，管理员免计。先持久化预留次数，再执行传送；执行失败退还次数。服务器异常退出时未确认的预留保守计入当天。

## 玩家轨迹

- 所有轨迹、在线玩家选择和历史坐骑图片接口都要求当前管理员身份。客户端隐藏按钮不是权限边界，服务端每次请求重新检查；采样时检查发起管理员权限。
- 每秒从游戏线程记录一次位置、方向和同乘坐骑。单次最长 86400 秒，最多同时 16 个玩家；同一玩家不能重复跟踪。
- 到时、手动结束、玩家离线、离开主世界、管理员权限失效或服务器停止时结束。记录存储在地图目录的 `player-tracks`，采样每十次持久化一次，正常结束立即写入；异常停止可能损失最后不到十秒。重启保留历史，不自动续录。
- 有模型时保存去元数据的运行时坐骑图集用于历史回放；没有模型时显示带名称的位置点。历史坐骑图集同样只允许管理员访问，不随安装包分发。
- 时间轴可拖动到任意时间，显示不晚于所选时间的最近一次采样。连续至少 60 秒、半径 2 格内且没有超过 5 秒采样间断的停留会标注。正在记录的回放增量更新。
- 管理员可以搜索玩家名、记录开始时间，点击历史绘制轨迹。取消坐骑复选框仅隐藏历史坐骑，不改变记录内容。
- 底部时间轴包含时间刻度、移动段、至少 60 秒的停留段、采样空缺与坐骑段；拖动游标定位，滚轮缩放、Shift + 滚轮平移；支持播放/暂停、全程视图、方向键（Shift 为 10 秒）与 Home/End。
- 历史列表提供删除及二次确认；删除会永久移除轨迹 JSON，并结束该条进行中的跟踪，重启不会恢复。共享坐骑图片文件保留，但没有其他轨迹引用时无法通过接口访问。
