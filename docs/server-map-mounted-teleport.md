# 地图携带坐骑／载具传送

版本保持 ServerMap 0.3.3、主程序 2.7.1-pre.3。需更新服务端模组与 MapHost 网页资源；本功能没有新增客户端网络协议。不会修改 QQ 机器人 `/tp` 的既有行为。

## 开关与权限

管理窗口新增“支持玩家携带坐骑或载具传送”，默认关闭，保存在当前世界的公告设置 `MountedTeleportEnabled`，HTTP/SSE 字段为 `mountedTeleportEnabled`。保存后立即生效，旧管理客户端不提交该字段时保留原值。

普通玩家还须开启“允许玩家消耗物品传送”。管理员保留免费、免副作用特例，但同样需要开启携带载具开关、担任实际驾驶员，并通过地形／空间检查。管理员驾驶不会替普通乘客免单，也不能在普通玩家传送被关闭时携带普通乘客传送。

只有 `IMountable.Controller` 指向的玩家可发起，且须确实占有该载具的可控制座位。乘客即使位于一个可控制座位，也不能冒充当前驾驶员。仅同步座位上的乘员；站在甲板上但未入座的人不自动包含。支持原版船、木筏、马鹿和继承 `VSAirshipmod.EntityAirship` 的飞艇，未知类型拒绝，不猜测其移动方式。

普通玩家不能传送到隐藏区域；关闭战争迷雾或切换隐藏区域预览不会解除这一限制。开启战争迷雾时，普通单人传送要求自己已探索目的地，坐骑整队传送只检查实际驾驶员的有效探索记录（包含服务器允许的盟友／同阵营共享），不要求乘客单独探索。只有乘客探索过、驾驶员未探索时不能传送。

隐藏区域检查覆盖玩家碰撞范围、载具和乘员占用范围，而不只检查落点中心。管理员驾驶也不能携普通乘客进入隐藏区域；全部成员都是当前管理员时保留原有隐藏区域例外。管理员受“管理员无视战争迷雾”设置控制，不再通过旧会话的管理员标记保留已被游戏撤销的权限。

## 地形和高度

| 类型 | 起点／终点 | 到达高度 |
| --- | --- | --- |
| 船／木筏 | 船体覆盖范围均为连续水面，排除冰、熔岩、陆地和不够深的浅水 | 保留起点相对水面的吃水偏移 |
| 马鹿 | 已站稳在地面，终点有支持且足够平整，不允许水面 | 地表顶面加安全间隙，按碰撞箱底部修正 |
| 飞艇 | 驾驶员 Y 严格高于目的地覆盖范围最高地表方块 Y；相等也拒绝 | 驾驶员传送前 Y + 5；换算座位偏移后移动飞艇主体 |

高度比较采用地图显示的地表方块坐标，而不是该方块顶部的站立坐标。例如驾驶员 Y=100、最高地表方块 Y=99，可以尝试传送；驾驶员到达 Y=105。若飞艇下部在这个高度仍碰撞地形则拒绝，不擅自继续抬高。水域使用水面所在方块进行飞艇高度比较，以避免水下落点。

加载载具与乘员覆盖的全部目标区块列后，检查服务器实际方块，不信任网页或地图缓存。使用原生当前碰撞箱，包括多碰撞箱载具；额外检查乘员、船底余量、乘船者眼部是否露出水面、世界边界和隐藏区域。只要存在普通乘员，整个到达范围都必须避开隐藏区域。

安全检查偏保守：水面高度差不超过 0.15 格，马鹿目标支持面高度差不超过 0.5 格。单实体水平碰撞跨度最多 64 格、垂直 128 格，最多 128 个碰撞箱、64 位玩家；单次空间扫描最多 200000 次方块检查。超过上限拒绝，不跳过检查。

## 每个人分别付费

以驾驶员本次路线的普通传送消耗为基准：

- 驾驶员支付 2 倍物品，承受 2 倍副作用。
- 每位普通乘客支付 1 倍物品，承受 1 倍副作用。
- 从各自快捷栏／背包扣费，不由驾驶员代付，不扣载具货物。
- 副作用仍是每次传送一次，不额外乘跃迁数；管理员对应倍率为 0。
- 任一需付费成员的路线为 0 跃迁、物品不足、生命值不足以承受扣减或缺少必要属性，整队拒绝。稳定性与饱食度扣减后最低为 0，双倍稳定性损失可超过 100 个百分点。

确认窗口逐人显示名字、角色、倍率、物品数量和副作用；不返回其他乘客背包持有数量。姓名按纯文本显示。成功传送时逐人写入审计日志。

## 一致性与回滚

确认有效期 1 分钟，绑定载具、驾驶员、座位乘员、倍率、设置、传送器网络和隐藏区域。位移超过约 0.15 格（垂直 0.25 格）、明显转向、换座／下车／上下人、离线或权限变化要求重算；允许少量待机浮动。飞艇到达高度使用最终执行前的驾驶员高度。

执行前再次计算路线价格，目标区块加载后再次校验整队、库存、副作用和地形。扣费、同步主体与全部座位乘员、应用副作用在同一次主线程操作内完成，不在扣费之后再开启异步传送。同步沿用原生实体传送的已加载回调处理和 `EntityPlayer.Onplrteleported`，保留座位、方向并重置速度／坠落状态。同步失败会恢复整队物品、位置和副作用；超时的待执行回调不能继续扣费。

报价、确认以及目标区块加载完成后均重新检查目的地权限；期间开启迷雾、新增隐藏区域、撤销共享探索或降级管理员都会按当前权限处理。拒绝时不扣费、不应用副作用、不移动玩家。隐藏区域保持 `403 / Hidden region`，未探索返回 `403 / teleport_unexplored`；网页显示对应原因，可见权限变化会立即作废旧确认和迟到的报价响应。

- `scripts/test-map-teleport-ui.cjs`：桌面／手机、管理员／普通玩家、逐人费用和副作用、安全姓名显示、开关持久化和实时失效。

上述自动化不等同于完整游戏客户端实测。真实 VSAirshipmod 多人画面同步、原版不同船型与复杂地形仍需本机进服验收；不自动部署或重启正在运行的客户端／服务端。
