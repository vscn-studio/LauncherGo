# 网页渲染与性能设置

语言图标右侧的 Tabler 齿轮按钮打开“网页设置”，匿名访问者也可使用。开关即时生效，通过 localStorage 按站点地址与地图路径保存；不能保存时弹窗显示提示，当前页面仍生效。恢复默认不会清除登录、图层偏好或地图数据。

| 设置 | 默认 | 行为 |
| --- | --- | --- |
| 兼容瓦片合成 | 开启 | 使用 normal 合成；关闭使用 Leaflet 原有的 plus-lighter 加法混合。用于排查地图空白、发白；普通合成可能显示细小瓦片接缝。 |
| 动态星空 | 开启 | 关闭后隐藏背景星星并停止绘制循环。 |
| 后台暂停刷新 | 开启 | 隐藏标签页时暂停常规地图图层、瓦片更新及相关轮询，返回时补齐。保留服务器事件连接及权限、可见性变更处理。关闭后浏览器仍可能限制后台定时器。 |
| 跟随自己 | 关闭 | 当前登录角色位置可见时保持居中；不依赖玩家图层勾选状态。手动拖动关闭跟随，弹窗、测距和截图选区期间暂停；未登录、离线或位置隐藏时不移动视角。 |
| 毛玻璃与阴影 | 开启 | 关闭界面模糊和装饰阴影；保留图标所需的颜色转换，移动端仍沿用已有简化规则。 |

本功能只需同步更新网页资源，包括 assets/web-settings.js、assets/web-settings.css 及本次修改的其他网页文件，无需更新游戏模组。自定义 WebRoot 也需要同步。

验证：`scripts/test-map-web-settings.cjs` 使用桌面和手机浏览器夹具验证按钮顺序、合成样式、设置持久化、跟随、后台暂停与可见性变更；通过 `PLAYWRIGHT_MODULE` 可指定现有 Playwright 安装。`scripts/test-map-fog-navigation.cjs` 覆盖原有权限刷新与迷雾导航。
