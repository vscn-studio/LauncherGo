# 地图区域标记与文字级别

适用主程序 `2.7.2-pre.1` / ServerMap `0.3.7`。需要同步新版网页和服务器模组。自定义 WebRoot 应包含 `area-markers.js`、`area-markers.css` 及更新的 `index.html`、`notebook.js`；无需删除旧瓦片或存档。

## 显示

地点名称和区域均支持整数显示区间 `x～y`，满足 `4 ≤ x ≤ y ≤ 15`，两端都包含；如 `8～8` 表示仅在 8 级显示。区域不再限定为四种类别，下面四档仅用于解释旧数据迁移与新草稿的初始建议值。

级别是网页底部显示的 Leaflet 级别，不是 URL 中的 `zoom`（后者为原生级别减去显示级别）。默认原生级别为 12。

| 显示级别 | 内容 |
| --- | --- |
| 4–6 | 第一类区域标记 |
| 7–9 | 第二类区域标记 |
| 10–11 | 第三类区域标记 |
| 12–13 | 第四类区域标记 |
| 13–15 | 旧地点名称的默认区间；领地文字和测距路线端点文字仍固定使用此区间 |

管理员新增或编辑地点标记时，可设置名称显示区间；普通玩家看不到该设置，编辑名称／描述等内容时保留管理员指定的区间。未配置的旧地点保持 13–15。选中地点不能绕过其显示区间；领地和测距文字仍固定在 13–15 级。弹窗中的名称、坐标和描述仍可阅读，图标和领地区域不受文字级别影响。隐藏区域的隐私规则与文字不变。低级别视图可通过缩放按钮到达 4 级，即使目前仅探索了很小的范围。

区域采用透明 SVG 图层，底色默认不透明度 8%、边界 25%、名称 58%。新增／编辑窗口可分别设置边缘、背景和文字的**透明度**（0% 不透明，100% 全透明）；对应默认值为 75%、92%、42%。边界比原默认值 32% 不透明度稍淡。旧数据缺少这些字段时使用新默认值，旧客户端编辑未提交透明度时保留已保存设置。

相邻矩形内部边线抵消，不显示框选片段的接缝。边线使用独立的 Leaflet 原生路径，按屏幕坐标重新投影，采用与当前领地区域一致的 2 CSS px 线宽；不再放入世界尺寸的 SVG 中缩放，避免外缘描边被 SVG 边界裁掉一半。透明度设置保持有效，原有区域形状不变。

名称取整个选区并集内**面积最大的轴对齐矩形**，可以跨越多个框选片段，但不能跨越擦除的空洞或未选择的部分。名称位于该矩形中心，沿左下至右上的完整对角线排列，角度为 `-atan2(高度, 宽度)`，字号按旋转后文字边界与矩形尺寸计算，保留 18% 余量。取消 25° 角度限制和 28 CSS px 字号上限；缩放一级时，文字与矩形一起等比例缩放。面积相同的矩形采用固定坐标顺序选择，避免缩放时文字跳位。右侧“区域标记”勾选状态按站点持久保存。

## 管理员操作

1. 右键 → **添加区域标记**，在工具栏输入最低／最高显示级别。修改后点击 **应用区间** 预览避让；完成和保存也会应用输入值。命名窗口同样可修改区间。
2. 使用 **框选** 拖动选取矩形，可反复叠加；使用 **擦除** 拖动扣除当前草稿中的像素。
3. 支持撤销／恢复；选择 **移动地图** 可平移，缩放按钮或滚轮可放大精修。手机支持单指拖拽框选与擦除。
4. 点击 **完成** 后才弹出名称、颜色设置；点击保存提交。Esc 优先关闭设置窗口，再按一次取消草稿。
5. 在显示级别内右键区域，或通过侧栏“管理区域标记”，可编辑／删除。普通左键点击区域不显示弹窗；仅管理员可用 Ctrl＋左键多选。删除区域标记不改变游戏领地、隐藏区域或其他标记。

管理窗口顶部支持按区域名称和区间搜索（例如 `10-11`）。列表也提供选择／取消选择按钮，供没有 Ctrl 键的触屏设备使用。

侧栏默认勾选玩家、坐骑、出生点、地点标记、游戏标记、隐藏区域和我的轨迹；其他图层（包括区域标记）默认不勾选。各项仍受登录与权限限制，浏览器已保存的个人勾选偏好优先，不因默认值调整而重置。

边界按**底图像素＝1 方块**对齐，采用半开整数坐标矩形。放大到 14–15 级仍能编辑任意区间，并预览与草稿显示区间有交集的已有区域。

- 擦除只操作当前草稿，不会修改其他区域。
- 只要两个显示区间包含任何相同级别，已有区域优先，新框选／区间变更会扣除重叠几何。例如 7～10 与 10～13 在 10 级同时显示，必须避让；7～10 与 11～13 不相交，可以覆盖相同地理范围。边缘可以贴合，原有区域不被修改。
- 服务端独立检查权限、坐标、复杂度和显示区间相交时的几何重叠。多人编辑使用全局修订号检测冲突；冲突保留草稿并提示重新打开，不覆盖别人的新数据。
- 普通玩家和访客只读；管理员权限以游戏当前权限为准。与隐藏区域相交的区域标记整体不向非管理员返回，避免泄露其名称及边界。

## 跨层级多选与合并

管理员 Ctrl＋左键切换区域选择。缩放到其他级别后，已选区域仍显示，并有临时虚线高亮；可继续选择其他区间。点击处多个区域重叠时，通过候选列表选择，避免误选。工具栏可逐项取消或清空选择。

选择至少两个区域后，点击“合并添加新区域”，创建它们实际形状的并集，保留空洞和不相连的部分，不用外包矩形填充。来源区域原样保留。

这里的更高层级指新区间整体位于更远视图：新区域的最高显示级别必须小于每个来源区域的最低显示级别。例如 10～11 与 12～13 可合并为 4～9 内的任意合法区间（如 5～8），不能使用 7～10。任何来源包含最低级别 4 时，不能继续向上合并。

合并避让所有与目标区间有交集的已有区域，完全不相交的区间互不避让。服务端按来源 ID 从当前存储重新计算并集和校验层级，不信任客户端传来的合并几何；使用相同修订号和复杂度限制。保存后新区域按自己的级别显示，多选高亮清除。

## 兼容与升级

- 旧区域只保存 `MinZoom` 时，分别按 4→6、7→9、10→11、12→13 恢复 `MaxZoom`，不改动原有区间与形状；后续保存会写入明确的最高级别。省略最高级别的旧请求在起始级别未变时保留已存区间。
- 地点在 `pois.json` 保存 `MinZoom`／`MaxZoom`，旧记录默认 13／15。请求中出现任一字段就必须同时提交两端，由服务端验证整数范围和当前管理员权限；普通玩家即使伪造请求也不能修改。
- **不能只更新主程序和网页而不更新服务端 ServerMap 模组。** 数据保存、权限校验和区域避让均在服务端模组执行。显示区间功能本身无需更新游戏客户端，但 2.7.2-pre.1 / ServerMap 0.3.7 的像素隐藏区域和完整原生地图同步需要客户端与服务端同时更新并重启。
- 网页通过 metadata 的 `poiZoomRanges` 与区域 API 的 `zoomRanges` 识别新能力；旧服务端仍可浏览，地点区间控件显示升级提示，区域新增／编辑不提交会被旧版忽略的区间数据。

## 数据和性能边界

按世界保存为 `area-markers.json`，与原有 `web-notebook.json` 隐藏区域数据分离，原子替换落盘。区域用稀疏矩形片段表示，不为世界面积申请像素数组。

- 最多 256 个标记，单标记最多 1024 个矩形，总计最多 8192 个矩形；名称最多 80 字符。
- 写入请求最多 128 KiB，几何运算有复杂度上限；超限不改变已有数据。
- 网页每 10 秒同步一次，同时监听更新通知；页面隐藏时停止定时请求。仅绘制当前级别及视口相交的区域，不需要重新渲染地形瓦片。
- 区域 SVG 随当前可见图层参与截图导出。
- 最大内部矩形通过坐标压缩和加权柱状图扫描计算：只使用矩形边界坐标，不按世界格数分配数组。结果和抵消后的边线按几何数组缓存，缩放和平移不会重复计算。

## 回归

`AreaMarkerTests` 覆盖持久化、修订冲突、自定义区间、旧数据兼容、共享显示级别避让、空洞、负坐标及容量限制。

`scripts/test-map-area-geometry.cjs` 对随机框选／擦除与逐像素参考结果进行比较，并验证边线抵消；最大内部矩形与小型随机形状的穷举结果比较，覆盖跨片段、空洞、负坐标、不相连区域和大坐标。

`scripts/test-map-area-markers-ui.cjs` 覆盖桌面／手机模拟的所有级别、触摸拖拽、命名时机、撤销／恢复、邻接、冲突提示和权限入口；验证原生边线路径与领地线宽一致、跨片段最大矩形、对角线位置及缩放一级文字尺寸翻倍。

原生 `MapTeleport` 回归夹具中的 `AreaMarkerChecks` 调用实际 HTTP 处理器，验证游客／玩家／管理员、权限撤销、请求头、非法几何、隐藏区域隔离和落盘。

`PoiZoomRangeTests` 与原生 HTTP 夹具覆盖管理员设置、普通编辑保留范围、非法区间及权限变更；浏览器回归覆盖自定义地点区间两端、区间外选中仍隐藏、旧服务端提示，以及区域自定义区间、同级避让与单级显示。
