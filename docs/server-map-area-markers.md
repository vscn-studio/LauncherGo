# 地图区域标记与文字级别

适用主程序 `2.7.1-pre.3` / ServerMap `0.3.3` 的本次构建；版本号保持不变。需要同步新版网页和服务器模组。自定义 WebRoot 应包含 `area-markers.js`、`area-markers.css` 及更新的 `index.html`、`notebook.js`；无需删除旧瓦片或存档。

## 显示

级别是网页底部显示的 Leaflet 级别，不是 URL 中的 `zoom`（后者为原生级别减去显示级别）。默认原生级别为 12。

| 显示级别 | 内容 |
| --- | --- |
| 4–6 | 第一类区域标记 |
| 7–9 | 第二类区域标记 |
| 10–11 | 第三类区域标记 |
| 12–13 | 第四类区域标记 |
| 14–15 | 地点标记、领地文字和测距路线端点文字 |

此前详细文字默认在 9 级及以下隐藏、10–15 级显示，并允许选中后例外显示；现在严格限制在 14–15 级。弹窗中的名称、坐标和描述仍可阅读，图标和领地区域不受文字级别影响。隐藏区域的隐私规则与文字不变。低级别视图可通过缩放按钮到达 4 级，即使目前仅探索了很小的范围。

区域采用透明 SVG 图层，底色不透明度 8%、边界 32%、名称 58%。相邻矩形内部边线抵消，不显示框选片段的接缝。名称沿区域内部矩形轻微倾斜，参考隐藏区域的缩放和裁切方式，限制最大字号为 28 CSS px；不会越过实际选区或填补擦除留下的洞。区域过小时文字等比例变小，不强制放大遮挡底图。右侧“区域标记”勾选状态按站点持久保存。

## 管理员操作

1. 右键 → **添加区域标记**，在工具栏选择四种显示级别之一。
2. 使用 **框选** 拖动选取矩形，可反复叠加；使用 **擦除** 拖动扣除当前草稿中的像素。
3. 支持撤销／恢复；选择 **移动地图** 可平移，缩放按钮或滚轮可放大精修。手机支持单指拖拽框选与擦除。
4. 点击 **完成** 后才弹出名称、颜色设置；点击保存提交。Esc 优先关闭设置窗口，再按一次取消草稿。
5. 在显示级别内点击区域，或通过侧栏“管理区域标记”，可编辑／删除。删除区域标记不改变游戏领地、隐藏区域或其他标记。

边界按**底图像素＝1 方块**对齐，采用半开整数坐标矩形。放大到 14–15 级仍能编辑任意类型，并预览同类型的已有区域。

- 擦除只操作当前草稿，不会修改其他区域。
- 同类型已有区域优先，新框选自动扣除重叠部分；边缘可以贴合。不同类型可以覆盖相同地理范围，在不同级别分别显示。
- 服务端独立检查权限、坐标、复杂度和同类型重叠。多人编辑使用全局修订号检测冲突；冲突保留草稿并提示重新打开，不覆盖别人的新数据。
- 普通玩家和访客只读；管理员权限以游戏当前权限为准。与隐藏区域相交的区域标记整体不向非管理员返回，避免泄露其名称及边界。

## 数据和性能边界

按世界保存为 `area-markers.json`，与原有 `web-notebook.json` 隐藏区域数据分离，原子替换落盘。区域用稀疏矩形片段表示，不为世界面积申请像素数组。

- 最多 256 个标记，单标记最多 1024 个矩形，总计最多 8192 个矩形；名称最多 80 字符。
- 写入请求最多 128 KiB，几何运算有复杂度上限；超限不改变已有数据。
- 网页每 10 秒同步一次，同时监听更新通知；页面隐藏时停止定时请求。仅绘制当前级别及视口相交的区域，不需要重新渲染地形瓦片。
- 区域 SVG 随当前可见图层参与截图导出。

## 回归

`AreaMarkerTests` 覆盖持久化、修订冲突、不同级别重叠、同类型保护、空洞、负坐标及容量限制。

`scripts/test-map-area-geometry.cjs` 对随机框选／擦除与逐像素参考结果进行比较，并验证边线抵消。

`scripts/test-map-area-markers-ui.cjs` 覆盖桌面／手机模拟的所有级别、触摸拖拽、命名时机、撤销／恢复、邻接、冲突提示和权限入口。

原生 `MapTeleport` 回归夹具中的 `AreaMarkerChecks` 调用实际 HTTP 处理器，验证游客／玩家／管理员、权限撤销、请求头、非法几何、隐藏区域隔离和落盘。
