# 地点标记图片

管理员在网页“管理内容”中开启“允许地点标记添加图片”，默认关闭。每个地点支持一张图片，可替换或移除；编辑地点的原有权限保持不变。

- 上传入口位于描述输入框下方，支持 JPEG、PNG、WebP、BMP。
- 文件不超过 5 MiB（界面显示 5 MB），宽、高分别不超过 2560 px。
- 服务端检查实际文件内容并完整解码，不依赖文件名或 MIME；拒绝 GIF、APNG、动画 WebP、损坏文件及超限图片。
- 读取 EXIF 方向来校正照片，然后从像素重新编码。输出不复制 EXIF/GPS、XMP、ICC 等原图元数据。
- 只保存长边不超过 480 px、1280 px 的两份静态 WebP，等比缩放、不放大小图，质量 82；原始上传内容只在请求处理内存中存在，不落盘。
- 详情按“坐标 → 480px 缩略图 → 描述”排列，点击图片用模态窗口查看 1280px 版本，可用关闭按钮、背景或 Esc 关闭。
- 开关关闭后，禁止图片上传和访问，并隐藏网页图片，但不删除缩略图。重新开启可恢复。
- 替换图片、移除图片或删除地点时，清理不再使用的缩略图。普通文字编辑及旋转不会改动图片。

## 存储及接口

地点数据仅新增可空的 `ImageKey`。图片保存在世界地图数据目录的 `poi-images/<key>-480.webp` 和 `<key>-1280.webp`。

`POST /api/v1/pois` 的可选字段 `imageData` 为原文件 Base64；省略保留已有图片，`null` 移除。客户端不能通过提交图片键绑定别人的图片。POI 写入并发受限，繁忙返回 429，客户端可重试。

`GET /api/v1/poi-image?id=<poi-id>&key=<key>&size=480|1280` 每次检查功能开关、图片与地点绑定关系及地点可见权限，包括隐藏区域。响应为 `image/webp`、`Cache-Control: no-store`，不提供原图端点。

`GET/POST /api/v1/announcement` 中的 `poiImagesEnabled` 控制功能；仅管理员可修改，旧客户端省略该字段时保持现有值。设置变更经事件推送同步到网页。

## 验证

- `PoiImageMetadataTests`：默认开关、持久化、旧客户端兼容以及普通编辑保留图片。
- `scripts/test-map-poi-images-ui.cjs`：桌面/手机上传、校验、预览、显示顺序、放大和移除。
- `scripts/test-map-poi-images-api.cjs`：由隔离游戏服务器的 notebook API 测试调用，验证真实编解码、EXIF 方向、元数据清除、权限与磁盘清理。
