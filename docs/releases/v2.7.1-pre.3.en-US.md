# LauncherGo 2.7.1-pre.3

## New and improved

- Place markers support adding, replacing and removing images. Administrators can enable this feature; it is off by default. Supports JPEG, PNG, WebP and BMP, up to 2560 × 2560 px and 5 MB. GIF and animated images are rejected.
- Only 480px / 1280px WebP thumbnails are retained. Photo orientation is corrected and EXIF/GPS and other metadata are removed; originals are not stored. Image access follows marker visibility permissions.
- Images retain their aspect ratio and appear below coordinates and above descriptions, with click-to-enlarge viewing. Close and remove controls use background-free cross icons.
- Translocator icons and connections change color together on hover or selection, without thicker lines or icon rings. Double-click an icon to jump to and select the other endpoint.

## Fixes and adjustments

- Map layers, My Markers and My Routes retain their visibility settings after reloading the page.
- Route planning starts immediately. Name and color are requested only when saving; cancelling the save dialog preserves the draft.
- Renamed the context-menu action to "Add place marker". Editor rotation is limited to −60° through +60°; out-of-range legacy angles reset to zero.

## Embedded mods and upgrade

- Updated ServerMap to **0.3.3**. ServerAuth **1.1.0**, Gateway Redirect **1.2.0** and Server Bridge **2.1.0** remain unchanged.
- Stop the game server and map service before updating the launcher, ServerMap mod and web files together. Update custom WebRoot files as well. No world saves or map caches need to be deleted.
