# LauncherGo 2.7.6-pre.4

## Added

- The Open API retrieves mod details from the official Mod DB. The `mods` arrays in `/api` and `/api/server`, and the `/api/mods` endpoint, now include the mod name, installed `version`, `author`, `description`, `coverUrl`, `latestVersion`, and `latestDownloadUrl`, while retaining `modId` and the mod page `url`.
- Mod descriptions are converted to plain text and limited to 360 characters. Latest releases use the existing semantic version comparison to avoid selecting an older version based on upload time.

## Improved

- Successful mod detail queries are cached for 30 minutes; failed results are cached for two minutes to reduce repeated requests while allowing retries.
- Failed Mod DB requests still return the local mod name, installed version, and fallback page URL. Mods with no available releases return empty latest version and download fields.

## Notes

- Launcher **2.7.6-pre.4**; embedded mod versions are unchanged. Update and restart LauncherGo to expose the new mod fields to clients; game mods do not need to be redeployed.
- `version` is the installed version. `latestVersion` and `latestDownloadUrl` refer to the latest Mod DB release and its download URL, without filtering by the current game version.
