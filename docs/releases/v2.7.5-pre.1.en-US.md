# LauncherGo 2.7.5-pre.1

## Mod identity and duplicates

- Mod identity is now read from `modinfo.json` `modid` instead of folder or ZIP file names.
- Before deploying the embedded authentication, server bridge, or gateway redirect mod, LauncherGo removes other ZIPs or folders with the same `modid` to reduce duplicate deployments.
- The mod list marks duplicate installations and multiple-version conflicts for the same `modid`. Conflicting rows use a pale red background, with the version and issue text shown in bold red.
- When refresh or rename encounters a display-name and version collision, the Mod ID is appended to avoid a rename conflict.

## Mod management

- Added mod search by name, Mod ID, version, or file path.
- ZIP and folder import now share one “Select file/folder” entry point, while still supporting multiple ZIPs and folders in one selection.

## Upgrade notes

- Launcher **2.7.5-pre.1**; embedded mod versions are unchanged.
- Authentication, bridge, and redirect mods continue to use directory synchronization. ServerMap continues to use a ZIP so it can be distributed as one map resource package; directory synchronization remains convenient for the embedded service mods.
