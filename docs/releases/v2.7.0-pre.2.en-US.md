# LauncherGo 2.7.0-pre.2

## Fixes

- Fall back to server logs for dashboard player names and online counts when no usable Server Bridge player snapshot is available.

- Read and persist translocator links directly from saved chunks, restore the network after restart, publish scan progress and retry failed reads.
- Fixed startup zoom animations overriding spawn positioning and sending refreshed pages to the world origin.
- Check tile color versions when restoring client palettes, prioritize visible stale tiles and prevent old zoom-tile writes from overwriting new colors.

## Upgrade notes

- Update the server-side ServerMap mod and web files, then restart the server. Keep the map cache; legacy tiles without color-version records will be redrawn progressively.
- For an already incorrect coordinate URL, click Locate Spawn or remove the coordinate parameters once. Valid shared locations remain unchanged.
