# LauncherGo 2.7.4-pre.4

## Added

- Profile configuration can now import flat world settings exported by the game and JSON containing only `WorldConfiguration`. Settings are merged into the current profile, preserving server settings, rules absent from the import, and mod attributes such as `exw*` and `scribe*`. Full `serverconfig.json` imports remain supported.

## Fixed

- Lowercase `playstyle` and `worldtype` now map to world settings. `playstyle: homosapiens` correctly displays as “Homo sapiens”; `gameMode: survival` continues to represent survival mode separately.
- The configuration form can read play style and world type previously stored in world rules by the importer. Saving moves them to the corresponding world settings and removes duplicate attributes.
- Importing world width, length and height updates the corresponding dimension settings, including values supplied as integer strings.

## Improved

- Renamed the import dialog to “Import game/server JSON” to clarify the supported configuration formats.

## Notes

- Launcher **2.7.4-pre.4**; ServerMap remains **0.4.4**. Other embedded mod versions are unchanged.
- Imports use the current profile's save and Mod paths. Custom mod attributes are retained in JSON; fields absent from the rules form do not yet have visual editors.
- World generation settings do not regenerate existing terrain. Create a new world to apply these settings fully.
