# LauncherGo 2.6.8

## Highlights

- Integrated ServerMap with per-profile configuration, deployment, and an independent map Host.
- Map Host supports HTTP/HTTPS, PEM/CRT certificates, KEY private keys, and reverse proxying to the ServerMap mod API.
- Moved ServerMap into the Manage menu with edit, deploy, start/stop, open-map, and certificate browsing actions.
- Fixed map asset 404s, the blank map page, and Release publish directory copy failures.
- Cleaned old Host runtimes and update installers so `.runtime` and `updates` no longer grow indefinitely.
- Removed the small package and small installer from the Release workflow.
- Added copyright and license notices for ServerMap, Leaflet, WebCartographer, and VS-LiveMap-Revival.
- Retained the QQ teleport-point and temporal-gear validation work, Discord bot integration, and other 2.6.8 prerelease features.
