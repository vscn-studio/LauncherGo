# LauncherGo 2.6.8

## Highlights

- Integrated ServerMap with per-profile configuration, deployment, and an independent map Host.
- Map Host supports HTTP/HTTPS, PEM/CRT certificates, KEY private keys, and reverse proxying to the ServerMap mod API.
- Moved ServerMap into the Manage menu with edit, deploy, start/stop, open-map, and certificate browsing actions.
- Added a custom `WebRoot` field, folder picker, and manual web update button. Updates replace bundled web files and licenses while preserving other files. An empty path uses the bundled pages; changing the directory requires a map restart.
- Fixed map asset 404s, the blank map page, and Release publish directory copy failures.
- Map search results now display spawn-relative coordinates. Separate X and Z fields support negative values, decimals, and Enter submission, with improved narrow-screen layout and search result visibility.
- Fixed inconsistent resolution of relative custom `WebRoot` paths.
- Fixed server startup after ServerHost runtime files are deleted by validating and rebuilding missing staged files automatically.
- Fixed window dragging stalls and persistent UI stuttering after starting any server, caused by synchronous cache cleanup and process enumeration during preference reads.
- Host and updater caches now use lifetime locks, serialized background deletion in batches, and delayed retries without retaining idle historical versions. Concurrent starts, crash restarts, downloads, and installation remain protected without an additional persistent cleanup process.
- Moved Host file preparation off the UI thread, bounded hashing memory, and removed a duplicate dashboard refresh.
- Added gateway snapshot write retries and removed historical statistics snapshots to prevent unbounded statistics files.
- Gateway bandwidth now uses a two-second sliding window with snapshots every 500 milliseconds to make short traffic bursts visible.
- Removed the small package and small installer from the Release workflow.
- Added copyright and license notices for ServerMap, Leaflet, WebCartographer, and VS-LiveMap-Revival.
- Retained the QQ teleport-point and temporal-gear validation work, Discord bot integration, and other 2.6.8 prerelease features.
