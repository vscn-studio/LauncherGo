# LauncherGo 2.7.5-pre.3

## Added

- Automated scheduled commands now support monthly, weekly, daily, hourly, and every N days, hours, or minutes.
- The scheduled command editor supports cycle-specific settings and previews the next five execution times.

## Improved

- Legacy scheduled commands that only contain a time are migrated to daily schedules, preserving existing configurations.
- Schedule settings support Chinese and English interface switching and are validated and normalized before saving.

## Notes

- Launcher **2.7.5-pre.3**; embedded mod versions are unchanged.
