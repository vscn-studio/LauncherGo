# LauncherGo 2.7.5-pre.2

## Mod identity fixes

- A ZIP or folder name is no longer reported as a Mod ID when `modinfo.json` has no valid `modid`. Such entries show `-` and an invalid metadata issue, and their enabled state cannot be toggled.
- Fixed invalid folder names such as `ServerAuth-1.1.0` being truncated to `ServerAuth-1.1`. The authentication mod's actual ID remains `launchergoauth`.

## Embedded mod deployment

- Authentication, server bridge, and gateway redirect mods now use the mod page's `Name-Version` folder naming rule, reading both values from `modinfo.json`.
- Deployment validates the bundled ID, version, and DLL and refuses to overwrite a folder owned by another mod. Redeployment can repair an existing authentication folder that has the expected DLL but no Mod ID.

## Upgrade notes

- Launcher **2.7.5-pre.2**; embedded mod versions are unchanged. A folder name and a Mod ID are separate fields: renaming a folder does not change the ID in valid `modinfo.json` metadata.
