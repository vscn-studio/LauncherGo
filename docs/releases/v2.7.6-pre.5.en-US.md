# LauncherGo 2.7.6-pre.5

## Improved

- The Open API mod list now includes only universal mods, excluding server-only and client-only mods.
- Mod card versions and download links now match the versions installed on the server instead of pointing to the latest Mod DB release. The download link is empty when Mod DB has no release matching the installed version.

## Notes

- Launcher **2.7.6-pre.5**; embedded mod versions are unchanged. Update and restart LauncherGo for the changes to take effect.
