# LauncherGo 2.7.6-pre.2

## Added

- The Open API records the online player count every five minutes and keeps the latest 2,016 samples (seven days).
- Player count history is persisted in each profile directory and remains available after restarting the launcher.
- `/api` and `/api/server` now return `playerCountHistory`, and `/api/players/history` provides the history as a dedicated endpoint. The response also describes the five-minute interval and retention count.

## Fixed

- Fixed Open API player history continuity when switching profiles or restarting the service.

## Improved

- Updated the Open API configuration panel to list the player history endpoint for easier client discovery.

## Notes

- Launcher **2.7.6-pre.2**; player history is stored as `openapi-player-history.json` in each profile directory, sampled every five minutes, and limited to 2,016 records (seven days).
