# LauncherGo 2.7.5

## Added

- Added an Open API under Connection Categories, with an independent port for each profile and support for starting multiple profiles at once.
- The Open API exposes server status, version, player count, uptime, name, description, and the installed mod list.
- Mod entries include the mod name, Mod ID, and the official ModDB link.
- Added server cover image selection and profile storage; the Open API serves the cover at `/api/cover` and returns its URL with server information.

## Fixed

- Fixed mod identity and deployment validation so invalid IDs, version conflicts, and truncated directory names no longer cause incorrect deployments.
- Improved the mod configuration workflow to reduce duplicate installs and accidental changes caused by multiple versions.

## Improved

- Scheduled commands now support monthly, weekly, daily, hourly, and every-N-days/hours/minutes cycles, with a preview of upcoming runs.
- Removed the Discord integration, including its configuration, UI, services, dependency, and related documentation.
- New installations now use `https://api.vintagestory.at/stable-unstable.json` as the game server download catalog URL.

## Notes

- Launcher **2.7.5**; embedded mod versions are unchanged.
