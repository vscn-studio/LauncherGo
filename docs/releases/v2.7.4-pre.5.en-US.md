# LauncherGo 2.7.4-pre.5

## Added

- QQ bot switches for game chat, player join/leave/death events, server notifications, and new QQ player bindings. Existing settings default to enabled and saved player bindings are retained.
- Mod import accepts multiple ZIP files and multiple mod folders in one selection list.
- QQ and Discord mod archive commands include top-level `Mods/` and `ModConfig/` folders.

## Improved

- Imported ZIPs and folders use the name and version from `modinfo.json` as `Name-Version`. Refresh can rename existing mods, and online updates follow the same rule.
- Import replaces an existing item only when its mod ID matches, avoiding accidental replacement of another mod.

## Notes

- Launcher **2.7.4-pre.5**; embedded mod versions are unchanged.
- Disabling QQ player binding prevents new bindings. Existing bindings remain available for player information and teleport commands.
