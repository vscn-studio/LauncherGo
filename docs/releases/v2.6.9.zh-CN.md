# LauncherGo 2.6.9

## 新增

- “我的标记”更名为“游戏标记”；地点弹窗使用编辑／复制链接图标按钮，传送器两端弹窗可复制各自的坐标链接。
- 网页管理新增标题、SEO 描述／关键词和 favicon 链接设置，保存即生效；服务端 HTML 同步输出 SEO 与 Open Graph 标签，仅管理员可修改。
- “我的标记”支持添加、编辑、删除及分享。右键“添加游戏标记”提供名称、置顶、已保存名称建议、颜色和原始图标选择，可调整 XYZ；修改直接同步游戏路径点，离线玩家下次进入也可读取。
- 标记分享与路线一致：公开预览独立快照，登录后主动保存为自己的游戏标记；原标记编辑不改变已有快照，删除会撤销分享。隐藏区域、玩家所有权、排队超时取消检查覆盖读写与导入操作。
- 搜索支持本人标记的名称、说明、图标名称，以及规划路线、出生点、管理员隐藏区域；点击结果自动显示对应图层，路线缩放到完整范围。新路线先弹窗输入名称与颜色，再开始绘制。
- 头像由服务器请求客户端实际头部模型及所用贴图片段，单后台任务生成并缓存 256×256 PNG；不再依赖预渲染素材或第三方接口。支持重连刷新、归属和令牌校验、分片限额；备用图层仍可通过 `AvatarAssetsPath` 配置。
- 隐藏区域弹窗使用单行图标按钮，新增“是否游戏内隐藏”；启用后遮挡新版客户端的大地图、小地图及区域内标记提示，管理员也适用，关闭后恢复显示。
- “我的标记”只显示当前登录玩家的游戏路径点，保留名称、说明、原始图标、颜色及 XYZ，约每 5 秒刷新。
- 右键复制坐标链接；“规划路线”支持左键折线、撤销、命名、配色、编辑、删除和右键分享。分享链接直接预览，其他玩家点击“保存到我的轨迹”后才会保存独立副本；删除原轨迹会撤销其分享链接。
- 地图渲染进度展示扫描、排队、处理中、重试、已完成及等待游戏保存数量。
- 管理员右键选定起点后，左键点击对角位置框选隐藏区域，支持编辑边界和解除隐藏；以对角文字标识，“隐藏区域”复选框仅切换管理员预览。服务器同时遮挡瓦片、过滤相关数据接口，旧管理员会话不会保留已撤销的权限。

## 修复

- 玩家头像改为正面取景，移除侧转和俯仰，避免左右镜像；旧侧脸缓存自动失效并重新生成。
- 修复多面数角色头像触发 `Head texture limit`，逐面贴图合并为有界图集；采集失败、模型超时和打包失败及时反馈到网页，不再持续显示等待模型。
- 游戏内隐藏区域遮挡不再覆盖添加标记弹窗；管理员网页勾选“隐藏区域”时也隐藏对应地图瓦片。头像采集改为读取原生头部网格，支持装备跨图集贴图，并增加采集日志及等待／失败状态提示。
- 优化地图启停：未变化的模组包跳过部署，Host 与网页资源复用文件指纹，仅重新读取变化的文件；停止时主动取消实时连接和挂起请求。按钮增加启动中／停止中状态与防重复操作，日志记录启停各阶段耗时、缓存命中和强制退出回退。
- 修复 Map Host 的共享 Cookie 容器可能导致不同访客串用登录会话的问题；转发时仅使用当前浏览器请求的 Cookie。
- 修复部署 ServerMap 后服务器可能长时间停留在 `WorldReady` 的问题：区块事件不再等待地图数据库查询锁，存档扫描延后到 `RunGame` 后启动。
- 修复区块变化触发全表索引反复重建的问题，改为按列查询已保存的区块切片，并使用可无阻塞重置的有界缓存。
- 修复关闭 ServerMap 配置后仍启动数据库扫描的问题。
- 服务器启动改为分阶段限时：Host 缓存准备 120 秒、控制通道 60 秒、启动前后自动化各 10 分钟，避免首次文件准备耗尽原有 30 秒总限时。
- 记录各阶段及 Host 文件校验、复制、目录移动、租约获取的耗时；超时或取消后阻止后续启动，保留启动锁直到后台操作结束，并清理本次创建的进程。启动后脚本失败不再笼统判为服务器启动失败。

## 优化

- 缩小至 8 方块/像素及更远时隐藏领地、地点和路线文字，仅保留点击选中的标注；取消选中后隐藏，放大后恢复。
- 领地、地点和路线标注统一常规字体与 13px 字号，细描边替代粗白边；地点标注保留原色并自动匹配深浅描边。隐藏区域使用浅灰白字与细深边，继续按区域缩放和裁切。
- 新增地图控件统一深色玻璃风格；图标同步说明收进点击信息提示，访客隐藏规划、保存及个人列表等登录限定操作。
- 进度仅显示红（失败）、黄（排队／处理中／重试／待保存）、绿（已完成）的一条条形图，详情通过点击提示查看；零值色段完全隐藏，全零时显示可点击查看状态的空轨道。
- 地图笔记侧栏仅保留勾选开关，不再显示列表；勾选“我的轨迹”显示全部已保存路线，分享路线独立预览。
- 路线弹窗使用单行图标操作并保留提示与无障碍名称；右键菜单字号统一，三个地图笔记勾选项移到玩家列表上方，字号、间距和悬停效果与现有图层一致。
- 路线和区域操作工具栏按实际内容宽度收缩，手机端限制在视口内并自动换行，移除多余横向留白。
- 路线规划提供“撤销／恢复”，替换“撤销一点”；支持连续操作、无历史禁用，以及添加新点后清除恢复历史。
- 隐藏区域移除云雾、动画和高亮底块，改用类似领地的左下至右上对角文字；管理员显示区域名称，其他玩家显示“隐藏区域”。文字适配区域大小、随地图缩放并裁切在边界内，不覆盖相邻地图，无空闲动画重绘。
- 隐藏瓦片的 RGBA 数据仍在服务器端清除，相关数据继续过滤；管理员文字预览开关会刷新权限瓦片并记住选择，不改变其他玩家的隐藏规则。
- 地图网页适配手机与触屏：菜单、搜索和公告默认收起，优化横竖屏、安全区域、按钮尺寸和弹窗滚动；坐标操作和地点标记编辑无需右键。
- 合并实时图层与瓦片通知，复用未变化的图层及玩家标记，拖动和页面切到后台时暂缓刷新；手机玩家轮询间隔为 5 秒，并降低瓦片缓存与模糊效果开销。
- 初始地图扫描、手动全图渲染排队、配色重绘排队和保存处理移至后台；存档遍历采用分页读取，释放批次间的数据库读锁。
- 传送器索引和旧地图缩放瓦片补全延后执行并限速，增加扫描进度日志和停服取消机制，避免游戏线程等待地图任务结束。
- 新增 10 项调度、缓存并发和 SQLite 查询回归测试，并完成 1.22.3 服务端临时新存档及已有测试存档的启动、扫描和停服验证。
- 新增 13 项启动阶段、取消检查、租约释放及脚本进程清理测试，以及 14 项地图笔记、权限、图标安全与瓦片遮挡测试；补齐头像采集／渲染、启停、SEO 及缓存测试，全量 322 项测试通过。

- 补齐 Feather 图标署名、GPLv3 全文、95 个 NuGet 包的版权清单与原始许可证／第三方声明；发布检查验证许可证覆盖及原始声明校验和，并明确游戏资源缓存的版权归属。

## 注意事项

- 网页标题、SEO 和 favicon 配置需同时更新地图模组、WebRoot 与 Map Host；头像采集需服务端和客户端都更新模组，客户端更新后须完全退出游戏再启动。
- 已部署地图模组的服务器需先停服，再部署新版 `servermap.zip` 后启动；无需删除世界存档或地图缓存。
- 继续提供联网安装版与完整自包含携带版。
- 手机布局优化仅涉及 WebRoot，但本次新增标记、轨迹、进度与隐藏区域功能需要同时更新 `servermap.zip` 和 WebRoot；自定义网页目录请执行“手动更新”，然后刷新浏览器。
- 同时停止地图网页服务，更新 Map Host 后重新启动，以应用会话隔离修复。
- 专用服务器缺少游戏路径点图标时，管理员需安装新版地图模组并进入游戏一次，客户端会分批同步原始 SVG 并按世界缓存。同步前网页提示缺少图标，自定义图标需提供游戏 SVG 资源。
- 游戏标记修改会写回原生路径点，网页规划路线仍单独保存。隐藏区域始终过滤网页数据；开启“是否游戏内隐藏”后，新版客户端的大地图和小地图也同步遮挡（包括管理员）。无法收回此前已查看或下载的数据，不限制游戏内探索。
