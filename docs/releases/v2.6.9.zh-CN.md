# LauncherGo 2.6.9

## 新增

- 内嵌模组升级：ServerAuth 1.1.0、Gateway Redirect 1.2.0、Server Bridge 2.1.0、ServerMap 0.3.0。
- 游戏标记支持查看、新增、编辑、删除和分享，与游戏同步名称、原始图标、颜色及坐标。
- 路线规划支持命名、配色、撤销／恢复、编辑及分享导入；坐标、地点和传送器支持复制定位链接。
- 管理员可设置隐藏区域，屏蔽网页地图及相关数据，并可选同步隐藏游戏内地图。
- 根据玩家客户端模型和贴图，本地生成并缓存正面头像。
- 搜索支持游戏标记、规划路线、出生点及管理员隐藏区域。
- 网页管理支持设置标题、SEO 描述／关键词和 favicon 链接。

## 优化与修复

- 修复 Windows 单文件打包时版权检查误将 ILLink 构建工具视为发行依赖的问题。
- 修复地图模组导致服务器启动卡住、超时的问题；完善分阶段超时、耗时日志与取消处理。
- 加快地图启停，减少重复部署和文件读取；优化后台扫描与刷新，增加启动中／停止中状态及防重复操作。
- 优化手机布局、图标按钮和标注可读性；远距离缩放自动隐藏未选中文字，渲染进度使用可点击查看详情的三色进度条。
- 修复地图网页会话隔离问题，避免不同浏览器串用登录状态。
- 补齐第三方许可证、版权声明和发布校验，明确游戏资源仅用于地图展示、不随程序包分发。

## 升级提示

- 停止服务器和地图服务后，同步更新地图模组、Map Host 与 WebRoot；自定义网页目录需手动更新，无需删除存档或地图缓存。
- 头像和游戏内隐藏需更新客户端模组并完全重启游戏；缺少游戏标记图标时，管理员进入游戏一次即可同步。
