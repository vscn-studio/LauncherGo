# LauncherGo 2.7.1-pre.1

## New features

- Added “Teleport here” to the map context menu. Administrators teleport for free; players pay according to the measured route's translocator jump count. Routes with zero jumps cannot use player teleport.
- The management window can enable player item teleport (off by default), configure an item code (default `game:gear-temporal`), and set the item cost per jump (default 1). Loaded vanilla and mod items are supported.
- Optional side effects include temporal stability loss, saturation loss and health loss. They are disabled by default and apply once per successful teleport. Insufficient health blocks teleportation; administrators are exempt.
- Confirmation shows costs and side effects. The server rechecks settings, permissions, position and inventory after loading the destination, protecting against duplicate charges and stale confirmations.

## Improvements and fixes

- Fixed black VS Roofing pixels by resolving actual roof materials, frames, snow and infill after roof definitions finish loading.
- Fixed white pixels for ground storage and legacy piles by sampling the stored collectibles, with stable selection for mixed inventories.
- Automatically request missing dynamic collectible colors and redraw stale tiles; fixed first-time color-stamp writes failing when the directory did not exist.
- Improved mobile map controls, popups, text overflow and zoom behavior.
- Bridge relays start from the latest event and resume after reconnecting without replaying old messages; improved cancellation and cleanup.
- Hidden translocator endpoints no longer expose destination coordinates or lines. Visible endpoints can show an unknown destination.
- An empty WebRoot selects the bundled page; improved saving, restart notices and duplicate-operation protection when updating web files.

## Embedded mods and upgrade notes

- Updated ServerMap to **0.3.1**. No other embedded mod source changed since `5519b5eeff5daabc3d2ae3e9db6d820ee75b0343`; ServerAuth **1.1.0**, Gateway Redirect **1.2.0** and Server Bridge **2.1.0** remain unchanged.
- Stop the game server and map service before updating LauncherGo, ServerMap and web files. Update custom WebRoot directories too. Keep existing saves and map caches.
- Ground-storage colors also require an updated administrator client to reconnect and upload the new colormap. Existing tiles are then redrawn progressively.
