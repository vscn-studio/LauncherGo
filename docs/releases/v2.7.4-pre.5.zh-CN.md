# LauncherGo 2.7.4-pre.5

## 新增

- QQ 机器人新增游戏聊天、玩家进出与死亡、服务器通知转发开关，并可关闭新的 QQ 玩家绑定。旧配置默认开启，已有绑定资料会保留。
- 模组导入支持同时选择多个 ZIP 文件和多个模组文件夹。
- QQ 和 Discord 的模组文件打包指令会同时导出 `Mods/` 与 `ModConfig/` 两个顶层文件夹。

## 优化

- 导入模组时根据 `modinfo.json` 将 ZIP 或文件夹命名为“模组名称-版本号”；刷新模组列表可整理已有模组名称，在线更新也采用相同规则。
- 同名导入仅替换相同模组 ID 的内容，避免误覆盖其他模组。

## 注意事项

- 主程序 **2.7.4-pre.5**；内嵌模组版本不变。
- QQ 绑定开关只阻止新绑定；已有绑定仍可用于玩家信息和传送指令。
