# LauncherGo 2.7.6-pre.4

## 新增

- 开放 API 从官方 Mod DB 获取模组详情，`/api`、`/api/server` 的 `mods` 和 `/api/mods` 返回模组名称、已安装版本 `version`、作者 `author`、介绍 `description`、封面 `coverUrl`、最新版本 `latestVersion` 和下载直链 `latestDownloadUrl`，保留 `modId` 与模组页面链接 `url`。
- 模组介绍转换为纯文本并限制为最多 360 个字符；最新发布版本复用语义版本比较逻辑，避免按上传时间选中旧版本。

## 优化

- 模组详情成功查询缓存 30 分钟，失败结果缓存 2 分钟，减少重复请求并允许后续重试。
- Mod DB 请求失败时仍返回本地模组名称、已安装版本和回退页面链接；无可用发布版本时返回空的最新版本和下载地址。

## 注意事项

- 主程序 **2.7.6-pre.4**；内嵌模组版本不变。更新并重启 LauncherGo 后，客户端可读取新增模组字段，无需重新部署游戏模组。
- `version` 表示已安装版本，`latestVersion` 与 `latestDownloadUrl` 表示 Mod DB 中的最新发布版本及其下载地址，不按当前游戏版本筛选。
