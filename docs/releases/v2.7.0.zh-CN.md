# LauncherGo 2.7.0

## 优化与修复

- 仪表盘在线玩家在服务器桥接不可用时回退到日志解析结果，保留在线人数和玩家名称。
- 地图渲染支持视野优先、共享地形读取和合并缩放瓦片更新；后台索引分批处理并持续重试失败读取。
- 传送器网络从存档直接读取并持久保存，服务器或地图重启后恢复完整网络。
- 客户端真实色表同步后按颜色版本刷新旧瓦片，不再写入固定回退色，避免旧缩放瓦片覆盖真实颜色。
- 修复无坐标链接刷新时跳到世界远端的问题，默认以游戏出生点为中心并补齐定位参数。

## 升级提示

- 更新服务器端 ServerMap 模组和网页后重启服务器，无需删除地图缓存；旧颜色瓦片会在色表同步后逐步重绘。
