# LauncherGo 2.7.0-pre.2

## 修复

- 仪表盘在线玩家在缺少可用服务器桥接数据时回退到日志，保留玩家名单和在线人数。

- 传送器索引从存档直接读取并持久保存，重启后恢复已有网络，扫描期间持续更新并重试失败项。
- 修复网页初始化缩放动画覆盖出生点定位、刷新后跳至世界原点的问题。
- 恢复客户端色表时检查旧瓦片颜色版本，优先刷新视野内旧色区域，避免缩放瓦片旧结果覆盖新颜色。

## 升级提示

- 更新服务器端 ServerMap 模组和网页后重启服务器，无需删除地图缓存。首次更新会逐步重绘没有颜色版本记录的旧瓦片。
- 浏览器已保留错误坐标时，点击“定位出生点”或移除 URL 坐标参数一次；有效分享链接仍保留原定位。
