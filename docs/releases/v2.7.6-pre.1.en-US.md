# LauncherGo 2.7.6-pre.1

## Added

- The Open API records the online player count once per hour and keeps the latest 168 hourly points (seven days).
- Player count history is persisted in each profile directory and remains available after restarting the launcher.
- `/api` and `/api/server` now return `hourlyPlayerCounts`, and `/api/players/history` provides the history as a dedicated endpoint.

## Fixed

- Fixed Open API player history continuity when switching profiles or restarting the service.

## Improved

- Updated the Open API configuration panel to list the player history endpoint for easier client discovery.

## Notes

- Launcher **2.7.6-pre.1**; player history is stored as `openapi-player-history.json` in each profile directory and is limited to 168 records.
