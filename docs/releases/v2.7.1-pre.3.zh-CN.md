# LauncherGo 2.7.1-pre.3

## 新增与优化

- 地点标记支持图片上传、替换和移除，由管理员开启，默认关闭。支持 JPEG、PNG、WebP、BMP，最大尺寸 2560 × 2560 px、最大文件 5 MB，不支持 GIF 或动画图片。
- 只保留 480px / 1280px WebP 缩略图，校正照片方向并移除 EXIF/GPS 等元数据，不保存原图；图片访问遵循地点可见权限。
- 地点图片按原比例显示在坐标下方、描述上方，支持点击放大；关闭与移除改为无背景叉号按钮。
- 传送器图标与连线同步变色，悬浮或选中时保持线宽，不添加图标外圈；支持双击跳转并选中另一端。

## 修复与调整

- 刷新网页后保留地图图层、我的标记和我的轨迹的勾选状态。
- 路线规划直接开始，仅保存时弹出名称与颜色设置，取消保存后保留草稿。
- 右键菜单改为“添加地点标记”；编辑窗口中的旋转角度限制为 −60°～+60°，旧数据超界时归零。

## 内嵌模组与升级

- ServerMap 升级至 **0.3.3**；ServerAuth **1.1.0**、Gateway Redirect **1.2.0**、Server Bridge **2.1.0** 保持不变。
- 停止游戏服务器与地图服务后，同步更新启动器、ServerMap 模组和网页；自定义 WebRoot 也需更新。无需删除存档或地图缓存。
