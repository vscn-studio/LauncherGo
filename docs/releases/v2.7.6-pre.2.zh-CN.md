# LauncherGo 2.7.6-pre.2

## 新增

- 开放 API 每 5 分钟记录一次在线玩家数量，最多保留最近 2016 个采样点（7 天）。
- 玩家数量历史数据持久化到档案目录，重启后继续使用已有记录。
- `/api` 和 `/api/server` 返回 `playerCountHistory`，并新增 `/api/players/history` 独立查询接口；响应同时说明 5 分钟采样间隔和保留点数。

## 修复

- 修复开放 API 玩家数量历史数据在档案切换和服务重启后无法连续使用的问题。

## 优化

- 开放 API 配置面板补充玩家历史接口提示，便于客户端发现和使用历史数据。

## 注意事项

- 主程序 **2.7.6-pre.2**；玩家历史数据保存在各档案目录的 `openapi-player-history.json`，每 5 分钟采样一次，最多保留 2016 条记录（7 天）。
