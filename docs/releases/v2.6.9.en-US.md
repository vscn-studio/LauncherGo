# LauncherGo 2.6.9

## Added

- Renamed My markers to Game markers. Place popups use compact edit/copy-link icons; each translocator endpoint can copy its own coordinate link.
- Web management now supports page titles, SEO descriptions/keywords and favicon URLs. Admin-only changes persist and apply immediately; initial HTML includes SEO and Open Graph metadata.
- Add, edit, delete and share My markers. The Add game marker context action offers a name, pinned state, saved-name suggestions, colors, original icons and editable XYZ. Changes update native game waypoints and connected clients; offline players receive them on their next visit.
- Marker links preview immutable snapshots and require explicit import into the recipient's game waypoints. Editing preserves existing shares; source deletion revokes them. Ownership, hidden-region filtering and cancellation of timed-out queued writes apply throughout.
- Search now includes owned waypoint names/descriptions/icon names, planned routes, spawn and admin-only hidden regions. Selecting a result reveals its layer and fits the entire route. New routes prompt for a name and color before drawing.
- Avatars use server-requested client head meshes and cropped textures, rendered as local cached 256×256 PNGs by a single worker. Transfers validate sender ownership, tokens, expiry and size; reconnects refresh cached portraits. Pre-rendered `AvatarAssetsPath` layers remain optional.
- Hidden-region popups use single-row icon actions. A new opt-in "Hide on in-game maps" checkbox synchronizes reversible full-map/minimap masks to updated clients, including admins, and suppresses hidden-region marker tooltips.
- My markers shows only the signed-in player's game waypoints, preserving names, descriptions, original icons, colors and XYZ, refreshed about every 5 seconds.
- Right-click coordinate links and manual route planning with polyline vertices, undo, names, colors, editing, deletion and right-click sharing. Links preview immediately; signed-in recipients explicitly save an independent copy. Deleting the source route revokes its shares.
- Render status shows scanning, queued, active, retrying, completed and awaiting-save work without inventing a percentage while totals are unknown.
- Admin-only rectangular hidden regions: right-click the first corner, select the opposite corner, then edit or remove as needed. Diagonal labels and a preview-only admin checkbox are backed by server-side tile masking and API filtering. Revoked admin privileges do not survive in old web sessions.

## Fixed

- Render player portraits from the native model's front (-X) without extra yaw, pitch or horizontal mirroring; invalidate older side-view avatar cache keys for regeneration.
- Pack per-face avatar texture crops into bounded atlas pages to avoid `Head texture limit` on detailed characters. Client capture failures, model timeouts and packing errors now reach the web status instead of remaining "waiting for head capture".
- Keep in-game hidden-region masks below waypoint dialogs. Admin hidden-region previews now request masked terrain tiles. Avatar capture uses the completed native head mesh and supports equipment textures from item/block atlases, with capture logs and waiting/error tooltips.
- Faster map startup and shutdown: unchanged mod packages skip deployment, and Host/web assets reuse cached fingerprints instead of rereading unchanged contents. Shutdown cancels live streams and pending requests; buttons show Starting/Stopping and prevent repeated operations. Lifecycle logs include per-stage timings, cache reuse and forced-exit fallback.
- Disabled Map Host's shared backend cookie container, which could replay another visitor's login session. Only the current browser request's cookies are forwarded.
- Fixed servers potentially stalling at `WorldReady` after deploying ServerMap. Chunk events no longer wait for map database query locks, and save scans now start after `RunGame`.
- Replaced repeated full-table chunk index rebuilds with per-column saved-slice queries and bounded caches that can be reset without waiting for active readers.
- Fixed database scans starting even when ServerMap was disabled in its configuration.
- Replaced the shared 30-second startup timeout with per-stage budgets: 120 seconds for Host staging, 60 seconds for the control channel, and 10 minutes each for before/after-start automation.
- Added phase and Host staging checkpoint timings. Cancellation prevents subsequent launches, retains the startup lock until pending work settles, and cleans up processes created by the cancelled attempt. After-start script failures now explicitly report that the server process has already started.

## Improved

- Hide claim, POI and route labels at 8 or more blocks per pixel, except the clicked selection. Deselecting hides the label again; zooming back in restores labels.
- Claim, POI and route labels use a consistent 13px font and thin outlines instead of heavy white strokes. POIs retain their colors with luminance-aware outlines; hidden-region labels use pale gray text with a thin dark outline while preserving diagonal scaling and clipping.
- New map controls follow the dark-glass theme. Icon-sync guidance uses a clickable info tooltip, and guests no longer see private lists or sign-in-only planning/save actions.
- Rendering uses one red (failed), yellow (pending work), and green (completed) bar with clickable detail tooltips. Zero-value segments are fully hidden; an all-zero bar shows a neutral track with clickable status details.
- Notebook sidebar lists are replaced by checkbox-only controls. Checking My routes displays every saved route, independently of shared-route previews.
- Route popups use single-row icon actions with tooltips and accessible names. Context menu fonts are consistent, and the three notebook toggles move above the player list with the existing layer checkbox styling.
- Route and region toolbars size to their text and buttons instead of stretching, with viewport-bounded wrapping on mobile.
- Route planning replaces Undo point with Undo / Redo, supporting consecutive operations, disabled empty history and redo invalidation when a new point is added.
- Hidden regions replace fog, animation and background highlights with claim-style diagonal labels running bottom-left to top-right. Admins see region names; other players see "Hidden regions". Labels fit region dimensions, scale with map zoom and are clipped to their boundaries, with no idle animation redraws.
- Protected tile RGBA data remains erased server-side and related data stays filtered. The admin label-preview toggle reloads permission-sensitive tiles and remembers its state without changing other players' restrictions.
- Added a phone/touch layout with collapsible menus, search and announcements, landscape and safe-area support, larger controls and scrollable dialogs. Coordinate actions and marker editing no longer require a right-click.
- Batched live layer/tile notifications and retained unchanged overlays and player markers. Refreshes pause during map gestures and while the page is hidden; mobile player polling runs every 5 seconds with reduced tile buffering and blur effects.
- Moved initial map scans, full-render queueing, colormap redraw queueing, and save processing to background work. Save traversal uses paged reads that release database read locks between batches.
- Deferred and throttled translocator indexing and parent-tile backfilling, with scan progress logs and shutdown cancellation so the game thread does not wait for map tasks to finish.
- Added 10 scheduling, concurrent-cache, and SQLite query regression tests, along with startup, scanning, and shutdown checks on a 1.22.3 server using temporary new and existing test saves.
- Added 13 startup-stage, cancellation, lease-release, and script-process cleanup tests plus 14 notebook, ownership, icon-safety and tile-masking tests. Expanded coverage for avatar capture/rendering, lifecycle cancellation, SEO and caching; all 322 tests passed.

- Completed third-party notices: Feather icon attribution, full GPLv3 companion text, 95-package NuGet notice inventory and original upstream licenses; release checks verify license coverage and notice hashes.

## Notes

- Page titles, SEO and favicon settings require the updated mod, WebRoot and Map Host; avatars require updated server/client mods. Fully restart the game client after updating its mod.
- Stop servers with ServerMap installed before deploying the updated `servermap.zip`, then restart. World saves and map caches do not need to be deleted.
- The online installer and fully self-contained portable package remain available.
- Mobile layout changes only need WebRoot, but the new markers, routes, progress and hidden regions require both the updated game mod and WebRoot. Use the manual web update for custom web directories, then refresh the browser.
- Stop the map web service, update Map Host and restart it to apply the session-isolation fix.
- Dedicated servers omit game waypoint icons. An admin must join with the updated map mod to sync original SVG assets in small batches; these are cached per world. Missing icons are indicated until synced. Custom icons must be available as game SVG assets.
- Game marker changes write back to native waypoints; planned web routes remain separate. Hidden regions always filter web data. Enabling Hide in game also masks the world map and minimap on updated clients, including admins. This cannot retract previously viewed/downloaded data or restrict in-game exploration.
