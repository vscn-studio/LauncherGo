# LauncherGo 2.6.9

## Added

- View, add, edit, delete and share game markers, preserving in-game names, original icons, colors and coordinates.
- Plan named, colored routes with undo/redo, editing and share imports; copy location links for coordinates, places and translocators.
- Admin-managed hidden regions filter web terrain and related data, with optional masking on in-game maps.
- Generate and cache front-facing avatars locally from players' client models and textures.
- Search game markers, planned routes, spawn and admin-only hidden regions.
- Configure page titles, SEO descriptions/keywords and favicon URLs in web management.

## Improvements and fixes

- Fixed server startup stalls and timeouts caused by the map mod; improved per-stage timeouts, timing logs and cancellation.
- Faster map startup/shutdown with less repeated deployment and file reading; optimized background scans and refreshes, with Starting/Stopping states and duplicate-action prevention.
- Improved mobile layouts, icon buttons and label readability; distant unselected labels hide automatically, and a three-color render progress bar offers clickable details.
- Fixed web session isolation to prevent browsers from sharing another user's login state.
- Completed third-party licenses, copyright notices and release checks; clarified that runtime game assets are used for map display and not bundled with the application.

## Upgrade notes

- Stop the server and map service before updating the map mod, Map Host and WebRoot together. Manually update custom web directories; saves and map caches can be kept.
- Avatars and in-game masking require an updated client mod and a full game restart. An admin can join once to synchronize missing game marker icons.
