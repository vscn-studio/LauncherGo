# LauncherGo 2.6.9

## Fixed

- Fixed servers potentially stalling at `WorldReady` after deploying ServerMap. Chunk events no longer wait for map database query locks, and save scans now start after `RunGame`.
- Replaced repeated full-table chunk index rebuilds with per-column saved-slice queries and bounded caches that can be reset without waiting for active readers.
- Fixed database scans starting even when ServerMap was disabled in its configuration.

## Improved

- Moved initial map scans, full-render queueing, colormap redraw queueing, and save processing to background work. Save traversal uses paged reads that release database read locks between batches.
- Deferred and throttled translocator indexing and parent-tile backfilling, with scan progress logs and shutdown cancellation so the game thread does not wait for map tasks to finish.
- Added 10 scheduling, concurrent-cache, and SQLite query regression tests. All 255 tests passed, along with startup, scanning, and shutdown checks on a 1.22.3 server using temporary new and existing test saves.

## Notes

- Stop servers with ServerMap installed before deploying the updated `servermap.zip`, then restart. World saves and map caches do not need to be deleted.
- The online installer and fully self-contained portable package remain available.
