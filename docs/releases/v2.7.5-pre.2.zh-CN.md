# LauncherGo 2.7.5-pre.2

## 模组身份修复

- `modinfo.json` 缺少有效 `modid` 时，不再用 ZIP 或目录名称伪造模组 ID。列表显示 `-` 和“元数据无效”，并禁止切换该条目的启用状态。
- 修复无效模组目录名 `ServerAuth-1.1.0` 被截成 `ServerAuth-1.1` 的问题。认证模组的真实 ID 仍为 `launchergoauth`。

## 内嵌模组部署

- 认证、服务器桥接和网关重定向模组现在与模组页面采用相同的“名称-版本”目录命名规则，名称和版本均来自 `modinfo.json`。
- 部署前校验内嵌模组 ID、版本和 DLL；目标名称属于其他模组时停止部署，避免覆盖。已有认证 DLL 但缺少 Mod ID 的目标目录可通过重新部署修复。

## 升级提示

- 主程序 **2.7.5-pre.2**；内嵌模组版本不变。模组 ID 与目录名是不同字段，重命名目录不会改变有效 `modinfo.json` 中的 ID。
