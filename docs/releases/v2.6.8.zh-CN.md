# LauncherGo 2.6.8

## 主要更新

- 集成 ServerMap，支持按档案配置、部署和启动独立地图 Host。
- 地图 Host 支持 HTTP/HTTPS、PEM/CRT 证书和 KEY 私钥，并反向代理 ServerMap 模组 API。
- 服务器地图移入“管理”菜单，支持编辑、部署、启动/停止、打开地图和证书文件浏览。
- 修复地图网页资源 404、地图页面空白和 Release 发布目录复制问题。
- 清理旧 Host 运行时和更新安装包，避免 `.runtime` 与 `updates` 持续占用磁盘。
- 网关状态快照增加写入重试，并移除后端统计历史快照，避免统计文件无限增长。
- Release 工作流移除 small package 和 small installer。
- 补齐 ServerMap、Leaflet、WebCartographer 和 VS-LiveMap-Revival 的版权与许可证声明。
- 保留 QQ 机器人传送点及时空齿轮校验、Discord 机器人等 2.6.8 预发布阶段功能。
