# LauncherGo 2.6.8

## 主要更新

- 集成 ServerMap，支持按档案配置、部署和启动独立地图 Host。
- 地图 Host 支持 HTTP/HTTPS、PEM/CRT 证书和 KEY 私钥，并反向代理 ServerMap 模组 API。
- 服务器地图移入“管理”菜单，支持编辑、部署、启动/停止、打开地图和证书文件浏览。
- 新增自定义 `WebRoot`、目录浏览和“手动更新”按钮；同步内置网页与许可证，替换同名文件并保留其他文件。留空使用随软件更新的内置网页，更换目录后需重启地图。
- 修复地图网页资源 404、地图页面空白和 Release 发布目录复制问题。
- 地图搜索结果改为相对出生点坐标；定位拆分为 X、Z 输入框，支持负数、小数和回车，修复窄屏搜索结果遮挡。
- 修复自定义 `WebRoot` 相对路径解析不一致的问题。
- 修复误删 ServerHost 运行时文件后无法启动服务器的问题，启动时会自动校验并重建缺失文件。
- 修复配置读取同步清理缓存、枚举系统进程导致的拖窗卡顿和任意服务器启动后的持续界面卡顿。
- Host 与更新缓存采用使用锁保护、后台串行分批回收和延迟重试，不保留闲置历史版本；保护并发启动、异常重启以及更新下载和安装过程，不增加独立常驻清理进程。
- Host 文件准备移至后台，减少大文件哈希内存分配，并合并重复仪表盘刷新。
- 网关状态快照增加写入重试，并移除后端统计历史快照，避免统计文件无限增长。
- 网关实时带宽改为 2 秒滑动时间窗，状态快照每 500 毫秒更新，提高短时流量可见性。
- Release 工作流移除 small package 和 small installer。
- 发布形式统一为一个联网安装版和一个完整携带版，不再区分在线与离线安装版。安装版主程序保持自包含，ServerHost、GatewayHost 和 ServerMapHost 使用系统共享 .NET 10；携带版主程序与三个 Host 均完整包含所需 .NET，无需另行安装。
- 安装器按需下载并安装匹配的 x64 .NET Runtime 10 与 ASP.NET Core Runtime 10，校验微软官方来源、SHA512 和 Microsoft 签名；不额外安装 Windows Desktop Runtime，卸载 LauncherGo 时保留共享运行时。
- 启动 Host 前检查运行时及补丁版本兼容性，缺失时提示重新运行安装器修复；修复框架依赖 Host 误用主程序同目录自带运行时的问题。
- 地图与网关 Host 在 LauncherGo 关闭或崩溃后继续后台运行，重新打开时根据进程身份、端口和心跳恢复已有运行状态；增加控制锁与 Host 锁，防止重复启动、状态覆盖及 PID 复用导致的误操作。ServerHost 保持原有独立后台模式，不包含 Windows 重启后的自动启动。
- 地图 Host 使用独立、受使用锁保护的版本目录运行，避免升级时锁住安装目录；增加运行时检查回归测试和后台进程冒烟验证脚本。
- 补齐 ServerMap、Leaflet、WebCartographer 和 VS-LiveMap-Revival 的版权与许可证声明。
- 保留 QQ 机器人传送点及时空齿轮校验、Discord 机器人等 2.6.8 预发布阶段功能。
