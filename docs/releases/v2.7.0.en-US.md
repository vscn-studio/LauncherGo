# LauncherGo 2.7.0

## Improvements and fixes

- Fall back to server log parsing for dashboard player names and online counts when the Server Bridge is unavailable.
- Prioritize visible map regions, share terrain reads, and coalesce zoom-tile updates; background indexing is batched and retries failed reads.
- Read and persist the translocator network from saved chunks so the complete network survives server or map restarts.
- Refresh stale tiles after the client colormap is synchronized using color-version stamps, avoiding fallback colors and stale zoom tiles overwriting real game colors.
- Fixed coordinate-less page refreshes jumping to a distant world location; the map now opens at the game spawn and fills in location parameters.

## Upgrade notes

- Update the server-side ServerMap mod and web files, then restart the server. Keep the map cache; legacy color tiles are redrawn progressively after colormap synchronization.
