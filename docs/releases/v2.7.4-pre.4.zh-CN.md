# LauncherGo 2.7.4-pre.4

## 新增

- 档案配置支持导入游戏导出的扁平世界配置 JSON，以及仅包含 `WorldConfiguration` 的 JSON；合并到当前档案并保留服务器设置、未覆盖的规则和 `exw*`、`scribe*` 等模组字段。仍支持完整 `serverconfig.json` 导入。

## 修复

- 修复小写 `playstyle`、`worldtype` 未映射到世界设置的问题，`playstyle: homosapiens` 可正确显示为“智人”；`gameMode: survival` 仍单独表示生存模式。
- 已导入档案中误存于世界规则的玩法风格和世界类型可被界面正确读取，保存时写回世界设置并清理重复字段。
- 导入世界宽度、长度和高度时同步对应尺寸配置，支持整数形式的字符串。

## 优化

- 导入窗口标题更新为“导入游戏/服务器配置 JSON”，明确支持的配置格式。

## 注意事项

- 主程序 **2.7.4-pre.4**；ServerMap 保持 **0.4.4**，其他内嵌模组版本不变。
- 导入配置沿用当前档案的存档和 Mod 路径。自定义模组字段保存在 JSON 中，未列入规则表单的字段暂不提供可视化编辑。
- 世界生成设置不会重新生成已有地形，完整应用这些设置需创建新世界。
