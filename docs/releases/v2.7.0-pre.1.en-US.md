# LauncherGo 2.7.0-pre.1

## Improvements and fixes

- Prioritize visible map regions and coalesce zoom tile updates to reduce duplicate work.
- Prioritize stale tile redraws after client colormap synchronization, preventing persistent fallback colours.
- Open coordinate-less map URLs at the in-game spawn and populate the location parameters automatically.

## Upgrade notes

- Update the server-side ServerMap mod, Map Host and WebRoot. Embedded mod versions are unchanged.
