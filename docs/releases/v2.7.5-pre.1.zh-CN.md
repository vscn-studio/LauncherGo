# LauncherGo 2.7.5-pre.1

## 模组身份与重复项

- 模组身份统一读取 `modinfo.json` 的 `modid`，不再根据文件夹或 ZIP 文件名判断是否为同一个模组。
- 认证、服务器桥接和网关重定向内嵌模组部署前会清理同一 `modid` 的旧 ZIP 或目录，降低重复部署的概率。
- 模组列表会标记同一 `modid` 的重复安装项和多版本冲突。冲突模组整行淡红显示，版本号和问题提示使用红色加粗显示。
- 刷新或重命名模组时，显示名和版本发生碰撞会追加 Mod ID，避免覆盖或重命名失败。

## 模组管理

- 模组页面新增搜索，可按名称、Mod ID、版本或文件路径筛选。
- ZIP 与文件夹导入合并为一个“选择文件/文件夹”入口，仍支持一次选择多个 ZIP 和文件夹。

## 升级提示

- 主程序 **2.7.5-pre.1**；内嵌模组版本不变。
- 认证、桥接和重定向模组继续使用目录同步，ServerMap 继续使用 ZIP。目录同步便于内嵌服务按文件部署和更新；地图模组保持 ZIP 以便作为单个地图资源包分发。
