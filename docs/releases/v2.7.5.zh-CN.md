# LauncherGo 2.7.5

## 新增

- 连接分类新增开放 API，可为每个档案单独配置端口并同时启动多个档案。
- 开放 API 提供服务器状态、版本、在线人数、开服时长、名称、介绍和模组清单。
- 模组清单包含模组名称、Mod ID 及官方 ModDB 链接。
- 支持选择并保存服务器封面图，开放 API 可通过 `/api/cover` 获取封面并在服务器信息中返回封面地址。

## 修复

- 修复模组身份识别和部署校验问题，避免无效 ID、版本冲突和目录截断导致错误部署。
- 改进模组配置流程，减少重复安装项和多版本冲突带来的误操作。

## 优化

- 自动化定时命令支持每月、每周、每日、每小时及每隔 N 天/小时/分钟执行，并可预览后续执行时间。
- 移除 Discord 集成及其配置、界面、服务、依赖和相关文档。
- 新安装配置中的游戏服务器下载链接改为 `https://api.vintagestory.at/stable-unstable.json`。

## 注意事项

- 主程序 **2.7.5**；内嵌模组版本不变。
