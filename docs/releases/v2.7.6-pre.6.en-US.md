# LauncherGo 2.7.6-pre.6

## Added

- ServerAuth now provides the `/serverauth reload` admin command. LauncherGo automatically reloads authentication settings after saving or clearing them and displays the server's result, without polling configuration files.

## Fixed

- Authentication enablement, password / Discourse / OAuth2 login modes and callback listeners can be reloaded live. Disabling authentication restores movement for waiting players; reloading restarts pending authentication while authenticated players stay online.
- Disabling authentication keeps the mod loaded so it can be enabled again live. Settings are saved atomically; configuration read or listener binding failures retain the previous configuration and report the failure.

## Notes

- Launcher **2.7.6-pre.6**; ServerAuth **1.1.1**. Redeploy the authentication mod and restart the game server once after this update. Update the client authentication mod as well. Subsequent configuration saves apply live.
- After editing `ModConfig/serverauth.json` manually, run `/serverauth reload` as an administrator or from the server console.
- Enabling authentication from the disabled state also authenticates online players. Reloading while authentication is already enabled does not prompt authenticated players again.
- Reloading resets login deadlines for pending players; session duration applies to new sessions. Disabling remembered sessions or changing external login settings clears remembered sessions. Reloading invalidates old browser authentication links.
