模组仅在 LauncherGo 中显式点击“部署地图模组”后安装或替换；启动地图不会自动覆盖现有版本。

ServerMap 为 Vintage Story 提供浏览器地图、玩家位置、领地、传送器、地点标记、公告和路径测量功能。网页资源由 LauncherGo.ServerMapHost 独立提供，模组仅负责读取世界数据并提供本地 API。

当前版本（ServerMap 0.4.3 / LauncherGo 2.7.4-pre.2）：
- 统一模组清单、程序集和地图 API 版本为 0.4.3；主程序升级至 2.7.4-pre.2，其他内嵌模组版本不变。
- 配套 LauncherGo 将网页重置与模组部署分离：顶部使用“部署地图模组、启动／停止地图、重置网页、重建缓存、打开地图”，不再自动安装或覆盖地图模组。
- 手动部署先确认目标与版本，替换前备份并检查重复模组和确认后的文件变化；重置网页只覆盖内置同名网页文件，保留额外文件、用户配置、地图数据和瓦片缓存。
- 配套网页新增兼容瓦片合成、动态星空、后台暂停刷新、跟随自己、毛玻璃与阴影五项本地设置；探矿 tooltip 补充出生点相对 X/Z，加载、空结果和失败时也保留。
- 以上界面与维护功能属于 LauncherGo／Host／WebRoot，不包含在模组 ZIP 中。从 0.4.2 使用这些纯网页改进无需升级模组；更新模组本身后需手动重启相应游戏进程。

此前更新（ServerMap 0.4.2 / LauncherGo 2.7.4-pre.1）：
- 矿脉搜索点击真实探矿点显示竖向色条 tooltip：每种矿物显示名称、按真实矿块坐标去重的总量和逐 Y 层数量，最多的层最红。已移除采样详情窗口、剖面和地形快照功能。
- 有矿色段加厚并标注真实 Y，探矿半径整数倍刻度加粗；省略未检出矿物的高度并标记断轴，层数过多时通过“较高层／较低层”切换，避免纵向滚动。
- 服务端保存实际检出矿块坐标，重叠采样按最新搜索体积覆盖并去重。旧记录缺少坐标，提示重新探矿；不会把整个搜索体积的总数复制到每层。
- 右键删除本人同 X/Z 的记录；管理员可删除任意探矿点的全部记录，包括旧记录，保留相邻点。
- 统一色条 tooltip 和按钮样式，修复右键菜单遮挡及左键重复触发；点击空白处或按 Esc 可关闭菜单。

此前更新（ServerMap 0.4.1 / LauncherGo 2.7.3）：
- 玩家头像改为参考原版模型的斜上方三分之四视角，保留头部、颈部、躯干和双臂；腿部、手持物锚点及下半身服装不会进入头像。
- 头像底部使用独立于服装和手臂长度的固定解剖裁切线，裁切线与 256×256 图片底边齐平，不会因服装高度或下垂手臂改变缩放和底部位置。
- 头像传输格式升级为 v2 并刷新缓存命名空间；客户端与服务端都需更新至 0.4.1，旧头像会在外观重新采集后自动替换。
- 新增图层策略、图片管理、上传类型和大小限制、地点额度与每日传送次数配置。
- 新增“道路”图层与“道路配置”：按方块 Code 识别道路，默认支持 `chiseltools:pathedchiseledblock`、`game:stonepath-free`；可选从道路端点/边缘以末端道路方块自身高度向上、向下中继扫描（默认中继深度 2），发现楼梯后沿四周继续继承高度中继，适用于被遮挡的地下/向上楼梯。宽路、多层铺盖会合并为单条中心线，并依据 Vintage Story 的实际 `Block.WalkSpeedMultiplier` 在已配置道路的速度范围内从白到黄显示；道路图层启用后路线规划会优先使用加速道路。
- “传送器路线规划”在勾选道路后，按各路段实际速度优化步行段，包含中途传送器之间的道路；支持岔路、连续拐角和不同速度路段，不改变手绘地图轨迹或物品传送计费。取消勾选恢复原有规划，图层、道路数据或权限变化会刷新计算与缓存。
- 道路中心线按方块真实邻接关系连接，宽路岔口共用连接点，保留环路和只延伸一格的短支路；不同材质按实际经过的方块边界分段着色，不再因方块 Code、半格错位或路宽变化断开。存档保存后自动刷新道路（包括地下道路变化），无需管理员进入游戏；底图色表采集是独立流程。
- 隐藏区域支持 1 方块像素叠加、擦除、撤销／恢复和继续编辑，保存为单一区域；管理员可预览透明遮罩。
- 战争迷雾支持总开关、管理员豁免和地图 ID 盟友共享；区域标记按探索范围裁剪，普通玩家不能传送到隐藏或未探索区域，同乘时以驾驶员探索为准。
- 登录游戏后自动只读扫描当前世界的原生地图缓存，分批同步全部有效图块；完整传输且保存成功后准确替换自己的探索范围，校正旧算法多开的迷雾。中断、读盘或保存失败不应用半份结果，也不清空旧记录。
- 扫描期间和后续原生地图实际生成成功的区块继续增量同步，不使用玩家轨迹或固定半径。盟友共享、管理员豁免和隐藏区域仍独立生效。
- 历史缓存由客户端提供，可能被复制或修改，不能用本次连接的发包记录证明；本功能明确按客户端现有地图信任这部分数据。只上传区块坐标，不上传图片或修改游戏地图缓存。
- 地图 ID 盟友改为申请制：申请方显示等待，接收方允许后才建立双方共享；待处理申请最多保留 10 分钟，过期自动清理。
- 网站配置支持保存自定义 CSS 和 JS，网页加载时分别注入页面头部与末尾，便于管理员扩展样式和交互。
- 客户端与服务端都需更新模组并重启，网页需加载新版资源；网页热重载不能代替模组重载，无需删除存档或地图缓存。

VS Roofing 彩色地图：
- 按存档中每个屋顶的覆盖材料、椽架、积雪或填充块选择客户端上传的颜色；同一方块 ID 的不同材料不会混用颜色。
- 服务端在 GameReady（屋顶方块定义加载完成后）建立材质索引，日志显示 roofing definitions ready 的屋顶/椽架定义数量。
- 更新模组并重启游戏服务器后，旧彩色瓦片会自动重绘；已有动态屋顶色表可继续使用，无需删除存档或整个地图目录。

地面堆叠物品彩色地图：
- GroundStorage 和旧式锭堆、板堆、木柴堆等按存档中的实际物品取色，不使用共用方块的白色默认纹理；同格多个非空槽位按坐标稳定选色。
- 原版石头、木柴、锭等按纹理名称查找物品图集，避免旧数字编号取到其他纹理；过滤透明采样的隐藏 RGB，保留真实材质的绿色和自定义物品取色。
- 服务端与管理员游戏客户端都需要更新 ServerMap，重连后由客户端按物品/方块纹理图集上传颜色。旧色表会自动触发重新请求，旧瓦片会重绘，无需删除地图目录。
- 瓦片日志包含 groundstorage 和 groundstorage-missing-color 计数；缺少实体或物品颜色时保留透明像素，不用白色占位。

显示级别区间（ServerMap 0.3.4 / LauncherGo 2.7.1-pre.4）：
- 管理员可设置地点名称的 4～15 整数显示区间，旧地点默认 13～15，普通玩家编辑其他内容不重置区间。
- 区域由四种固定类别改为自定义显示区间，旧范围不变；任何共享显示级别的区域均自动避让，合并目标的最高级别须低于所有来源的最低级别。
- 本功能需要更新服务端模组和网页，未改变游戏客户端协议；已有支持 0.3.3 功能的客户端无需仅为显示区间更新。无需删除存档或地图缓存。

地图笔记（需同步更新模组与网页）：
- 动物坐骑图像使用独立骨骼副本计算固定站姿，不再固定行走、奔跑、跳跃或游泳时的屈腿动作；不会改动游戏中的真实动画，船和飞艇保留结构状态。此修复需更新骑乘客户端的同版本模组；旧图会在下一轮成功采集后替换，通常约 120 秒，无需删除地图缓存。
- ServerMap 0.3.3：网页右侧新增“坐骑”，记住勾选状态。仅显示正在骑乘的模型透明静态斜上方图集（偏离正上方 25°，16 方向切帧），固定地图光照并添加柔和轮廓阴影；水平最长边 ≤4 格时放大 2 倍，≥8 格保持原尺寸，中间平滑过渡，跟随载具位置和朝向；多人同乘合并，下马后移除，沿用玩家坐标与隐藏区域权限。
- 0.3.3 引入的方向图集使用 v2 通道，首次使用该坐骑功能时服务端和客户端均需更新至支持此通道的构建。首次坐骑图像需要同车至少一位骑乘玩家更新客户端 ServerMap；无图时留空，不以图标代替。标准座席/EntityShapeRenderer 接入原版马鹿、船与 VSAirshipmod 主体；单独渲染的特效或附件不保证包含，完整实机外观需上线前验证。详见源代码 docs/server-map-mounts.md。
- 在游戏内使用 /servermap psw <密码> 设置网页密码，再以玩家名登录网页。
- 管理窗口的“允许玩家消耗物品传送”默认关闭，管理员勾选并保存后普通玩家才可使用；设置持久保存且立即生效，关闭后未完成的玩家传送也会被拒绝。
- 登录后右键地图选择“传送到此处”（手机使用地图操作按钮）。角色须在线；管理员传送不消耗物品，也不受上述开关限制。
- 管理窗口可设置传送消耗物品 Code（默认 game:gear-temporal，支持已加载的原版/模组物品和可携带方块）及每次跃迁消耗数量（默认 1，范围 1–100000）。总消耗为测量路线跃迁数乘该数量，从快捷栏和背包合计扣除；跃迁数为 0 时不能传送，不按固定数字 ID 识别。
- “启用传送副作用”默认关闭。开启后可设置时空稳定性降低（0–100 个百分点）、饱食度扣减和生命值扣减（各 0–100000 点）；0 表示不扣除该项。副作用仅在每次成功传送后执行一次，不乘跃迁数；稳定性和饱食度最低为 0，生命值不大于扣减值时禁止传送，管理员不受影响。
- 传送确认显示实际物品 Code、总消耗、每跃迁数量和副作用。设置变更会要求玩家重新计算；最终落点加载完成后，服务端再次验证设置、生命值与物品，失败或超时不会收取消耗。
- 传送前显示跃迁数、消耗和持有数量，确认有效期为 1 分钟。落点加载后重新验证位置、权限、物品和地表空间；请停稳。隐藏区域或不可用落点不支持玩家传送。
- “支持玩家携带坐骑或载具传送”默认关闭，开启后仅实际驾驶员可发起，座位乘员一起传送。船／木筏只准水面到水面，马鹿只准地面到地面；飞艇驾驶员高度必须严格高于目标地表方块 Y，到达驾驶员 Y 为执行前 Y + 5，同时检查整个载具与乘员空间。
- 携带载具时驾驶员自行支付普通消耗的 2 倍并承受 2 倍副作用，每位普通乘客各支付 1 倍并承受 1 倍副作用；管理员仍免费、免副作用，但不能替普通乘客免单。任何成员不满足条件，整队不传送、不扣费。具体规则与验证范围见 docs/server-map-mounted-teleport.md。
- “我的标记”读取本人的游戏路径点，可通过右键“添加游戏标记”或标记弹窗添加、编辑、删除及分享；网页规划路线仍独立保存。
- 标记操作在游戏主线程写入原生路径点数据，并刷新在线客户端；存档随游戏保存落盘。网页最多为每人保留 2000 条游戏标记，排队超时的操作不会延迟执行。
- 标记分享保存在 ServerMap/<世界ID>/waypoint-shares.json：分享为独立快照，导入后成为接收者的游戏标记；源标记删除会撤销其分享，已导入副本不受影响。
- 专用服务器未包含完整路径点 SVG。管理员安装新版模组并进入游戏后会自动同步原始游戏图标，按世界保存在 ServerMap/<世界ID>/waypoint-icons；网页会提示尚未同步的图标。自定义图标需以 SVG 资源提供。
- “规划路线”：左键添加折线顶点，可撤销、命名、配色、保存与编辑。右键地图复制坐标链接，右键轨迹复制分享链接；手机可点击轨迹使用弹窗按钮。
- 分享链接可公开预览单条轨迹，其他登录玩家需主动点击保存，才会生成自己的独立副本。编辑原轨迹不改变已有分享快照，删除原轨迹会撤销其分享链接。
- 管理员右键选择“框选隐藏区域”，按住拖动预览矩形，松开后叠加或擦除；完成后仅设置名称和游戏内隐藏选项。右键隐藏区域可继续编辑形状或移除；“隐藏区域”复选框仅切换管理员预览，不影响其他玩家的限制。
- 区域编辑中的“是否游戏内隐藏”默认关闭；启用后约 3 秒内同步到新版客户端的大地图、小地图和区域内标记提示，管理员也隐藏。关闭可恢复，不删除客户端地图缓存；旧版或修改过的客户端不保证执行此显示规则。
- 头像默认向安装新版模组的玩家请求实际头部网格及所用贴图片段，服务器后台生成 256×256 PNG，保存在 ServerMap/<世界ID>/client-avatars；无需 AvatarAssetsPath，首次回传完成后网页自动刷新头像。
- 隐藏区域由服务器直接遮挡各缩放级别瓦片并过滤数据接口；与区域相交的路线和区域要素会保守地整体隐藏。规则无法撤回已经下载的数据，也不限制游戏内探索。
- 隐藏瓦片的 RGBA 像素全部清除，不以纯白填充；前端使用无背景的对角区域文字，随地图缩放并限制在隐藏边界内。
- 轨迹、分享与隐藏规则保存在 ServerMap/<世界ID>/web-notebook.json；建议随世界备份。该文件损坏时地图服务拒绝启动，避免意外暴露隐藏区域。
- 渲染进度为本次进程的队列统计，已完成不等于整个世界已生成；实时区块需等待游戏保存后渲染。

Incremental cache: first build extracts shared Brotli surface data. Normal restarts restore the persistent index/tasks; saved changes update columns and seasonal colors reuse the surface. Use /servermap cache rebuild (console/root only) after offline edits or backup restores. Existing maps and user data remain available. See docs/server-map-incremental-cache.md in the LauncherGo source.
